# 벽돌깨기 아케이드

우주를 배경으로 별 모양 공을 튕겨 벽돌을 깨는 게임입니다. 5개 스테이지와 다양한 아이템, 기온에 따른 공 속도 변화가 있습니다.

## 실행하기

`index.html`을 브라우저에서 열면 됩니다. 서울 날씨를 가져오려면 인터넷 연결이 필요합니다. 날씨를 가져오지 못하면 기본 속도로 게임이 시작됩니다.

방향키 또는 마우스와 터치로 패들을 움직이고 스페이스바로 일시정지할 수 있습니다. 화면 오른쪽 아래에서 테스트 기온을 설정할 수 있습니다.

날씨 데이터: [Open-Meteo](https://open-meteo.com/).
